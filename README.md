# Gross Profitability Factor Replication

## Overview
Replicated the Gross Profitability (GP/A) factor from Novy-Marx (2013) to evaluate its ability to predict stock returns.

## Approach
- Construct GP/A = (Revenue − COGS) / Assets  
- Merge CRSP & Compustat data  
- Form NYSE-based quintile portfolios (EW & VW)  

## Key Results
- High GP firms significantly outperform low GP firms  
- Stronger effect in equal-weighted portfolios  
- Results closely match original paper  

## Tools
Python, WRDS, Pandas, Financial Modeling
